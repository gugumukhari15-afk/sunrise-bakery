# Artisan Bakehouse Website

**Student Project – Part 1: Building the Foundation**

## Project Overview
Professional website for Artisan Bakehouse, a fictional local artisan bakery in Cape Town.

## Pages
- Home (`index.html`)
- About Us (`about.html`)
- Products (`products.html`) – with product images
- Services (`services.html`)
- Enquiry (`enquiry.html`) – form with validation
- Contact (`contact.html`) – contact form + two Google Maps

## How to add product images
1. Put your photos in the `images/` folder
2. Recommended names:
   - `sourdough.jpg`
   - `wholewheat.jpg`
   - `ciabatta.jpg`
   - `croissant.jpg`
   - `chocolate-cake.jpg`
   - `cinnamon-rolls.jpg`
3. Or change the `src` in `products.html` to match your file names
